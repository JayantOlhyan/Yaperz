# Component Catalog

## Key Components
1. `Header`: Sticky navigation, search toggle, and cart trigger
2. `Footer`: Multi-column links, newsletter subscription, payment icons
3. `ProductCard`: Responsive catalog card with quick-view and hover states
4. `CartDrawer`: Flyout shopping cart drawer with live subtotal calculation
5. `SearchOverlay`: Fullscreen search overlay with instant debounced filter
6. `StoriesBar`: Instagram-style ephemeral product stories
7. `LocationModal`: Store locator dialog for physical retail outlets
8. `SkeletonLoader`: Shimmer pulse loading placeholders for content suspense
9. `PWAProvider`: Service worker registration and install prompt manager
