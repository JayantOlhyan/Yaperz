# Technical Architecture: Yaperz E-Commerce

## Overview
Yaperz is a luxury streetwear storefront built with Next.js 16 (App Router), React 19, and TypeScript 5.

## Directory Layout
- `src/app/`: Next.js 16 App Router route tree
- `src/components/`: Modular React components and CSS Modules
- `src/context/`: Cart and client application state
- `src/lib/`: Pure utility functions and validators
- `src/types/`: Domain TypeScript type definitions
- `src/data/`: Static product catalog datasets
- `public/`: Static brand assets and manifest
