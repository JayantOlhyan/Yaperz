# Accessibility (a11y) Standards

## Guidelines
- Minimum 48px tap targets for mobile interactive controls
- Full keyboard navigation for dialogs and drawers with `Escape` key listeners
- ARIA landmarks (`role="dialog"`, `aria-expanded`, `aria-label`) on interactive components
- Semantic HTML tags (`<nav>`, `<header>`, `<main>`, `<footer>`, `<article>`)
