# Routing & Dynamic Segments

## Route Hierarchy
- `/`: Storefront landing page
- `/collections`: Category directory
- `/collections/[slug]`: Dynamic filtered category view
- `/products/[slug]`: Dynamic Product Detail Page (PDP)
- `/checkout`: Multi-step checkout flow
- `/account`: User profile and order history
- `/track-order`: Real-time order status lookup
- `/faq`: Help center and accordion questions
- `/policies/*`: Legal terms, privacy, returns, and shipping
